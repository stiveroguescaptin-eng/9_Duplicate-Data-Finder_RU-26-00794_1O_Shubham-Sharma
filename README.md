# Duplicate Data Finder

A simple and robust Python program that reads a text file, identifies and counts duplicate entries, and saves the cleaned, unique entries into a new file.

## Features

- **Exact matching** to identify identical records.
- **Normalization** by ignoring case sensitivity and extra whitespace.
- **Duplicate counting** to track how often each entry appears.
- **File handling** for reading from and writing to local text files.
- **Error handling** for empty files or missing input files.

## Files

- `main.py` – Python source code
- `data.txt` – Input data file
- `unique.txt` – Unique entries output file
